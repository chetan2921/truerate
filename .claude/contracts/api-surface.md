# API surface

| Side | Files |
|------|-------|
| server | `api/truerate/app.py` routes and the Pydantic response models they declare (`Report` is the whole analysis result) |
| client | `web/src/lib/api.ts` (fetch calls) and `web/src/lib/api-types.ts`, generated by `make types` (dumps `app.openapi()` to the git-ignored `web/openapi.json`, then runs `openapi-typescript`) |

Routes: `GET /api/health`, `POST /api/analyses` (202, `{id}`), `GET /api/analyses`, `GET /api/analyses/{id}`, `DELETE /api/analyses/{id}` (204, hides it from the recent list; the report still opens), `POST /api/analyses/{id}/quote`, `POST /api/batches` (202), `GET /api/batches` (the 10 newest, with done and total), `GET /api/batches/{id}`, `GET /api/rate-card` (503 until `truerate validate` has run), `GET /api/meta`, `GET /api/model-report`.

Change a route or a response model, then run `make types` and fix `api.ts` in the same session. The client fails at runtime, not at build time, when a field is renamed. The pipeline's result dict must match `Report`, or `GET /api/analyses/{id}` fails validation; `tests/test_app.py` reads a full result through it.

Plain verdicts (2026-10-11): `Analysis.outputs` and `BatchRow.outputs` are lists of `{key, status: good|warn|bad|info, title, detail}` from `truerate/outputs.py`, worked out from the stored result on every read, so old analyses get them too. `BatchRow` also carries `views_low`, `views_high`, `category_cost_per_1k`, `followers` and `category` for the comparison charts. `Report.web_rate` (`{found, low, high, summary, sources: [{title, url}]}`) is set only for creators bigger than anyone WLDD has booked: a Google-grounded Gemini search for a rate the web states for that creator. `Price.likely_low`/`likely_high` is the band 3x wide around the middle.

Brand match (2026-10-11): `POST /api/brands` (202, `{id}`; body `{brand, product?, budget?, count=10}`, brand is an Instagram handle or link, a website, or a name), `GET /api/brands/{id}` (`BrandRun`: status, step of 4, `result` with `brand` profile, ranked `picks` each with `sources`, `answers` and `reasons`, a `plan` within budget, and `to_price`, accounts seen with the brand without an analysis), `GET /api/brands` (10 newest).
