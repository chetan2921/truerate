# API surface

| Side | Files |
|------|-------|
| server | `api/truerate/app.py` routes and the Pydantic response models they declare (`Report` is the whole analysis result) |
| client | `web/src/lib/api.ts` (fetch calls) and `web/src/lib/api-types.ts`, generated by `make types` (dumps `app.openapi()` to the git-ignored `web/openapi.json`, then runs `openapi-typescript`) |

Routes: `GET /api/health`, `POST /api/analyses` (202, `{id}`), `GET /api/analyses`, `GET /api/analyses/{id}`, `POST /api/analyses/{id}/quote`, `POST /api/batches` (202), `GET /api/batches/{id}`, `GET /api/rate-card` (503 until `truerate validate` has run), `GET /api/meta`, `GET /api/model-report`.

Change a route or a response model, then run `make types` and fix `api.ts` in the same session. The client fails at runtime, not at build time, when a field is renamed. The pipeline's result dict must match `Report`, or `GET /api/analyses/{id}` fails validation; `tests/test_app.py` reads a full result through it.
